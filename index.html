ProjectWorth Support

Help for ProjectWorth 2.0, the local project planning and decision-support app for macOS.

ProjectWorth 2.0 · Updated 2 October 2026

Get help

ProjectWorth requires macOS 14 or later. Your project work stays on your Mac and does not require an account. ProjectWorth checks App Store entitlement status with Apple at startup and when needed, including purchased Pro and eligible Legacy Pro. Purchases and restore also use Apple services.

Starter and Pro

Starter lets you work with up to two active, non-paused projects. Pro is an optional one-time purchase that unlocks portfolio comparison, advanced analysis, decision support, forecasts, scenarios, focus cycles, weekly review, CSV import, and unlimited active projects.

Restore a Pro purchase

Open the Pro screen from Settings → General → Plan and choose the restore option. Restore uses the Apple account that made the purchase. If Apple cannot verify the purchase, check the account and network connection, then try again later.

Before requesting help

  1. Open ProjectWorth → Settings → About → Privacy and support and copy the version information.
  2. Describe what you did, what you expected, and what happened.
  3. Mention whether the problem occurs in Swedish, English, or both.
  4. Never attach a ProjectWorth backup unless you explicitly want to share the data it contains.

Protect your data

Create a restorable backup from Settings → Data → Backup → Create backup. A backup contains the complete local workspace, including the project data and preferences stored by ProjectWorth. If the local database cannot be opened, ProjectWorth shows a recovery screen where the original files can be archived before starting fresh.

Få hjälp

ProjectWorth kräver macOS 14 eller senare. Ditt projektarbete stannar på din Mac och kräver inget konto. ProjectWorth kontrollerar App Store-rättighet hos Apple vid start och när det behövs, inklusive köpt Pro och berättigad Legacy Pro. Köp och återställning använder också Apples tjänster.

Starter och Pro

Starter låter dig arbeta med högst två aktiva, icke-pausade projekt. Pro är ett valfritt engångsköp som låser upp portföljjämförelse, avancerad analys, beslutsstöd, prognoser, scenarier, fokuscykler, veckogenomgång, CSV-import och obegränsat antal aktiva projekt.

Återställ ett Pro-köp

Öppna Pro-skärmen via Inställningar → Allmänt → Plan och välj återställning. Återställningen använder det Apple-konto som genomförde köpet. Om Apple inte kan verifiera köpet, kontrollera kontot och nätverksanslutningen och försök igen senare.

Innan du kontaktar support

  1. Öppna ProjectWorth → Inställningar → Om → Integritet och support och kopiera versionsinformationen.
  2. Beskriv vad du gjorde, vad du förväntade dig och vad som hände.
  3. Ange om problemet uppstår på svenska, engelska eller båda språken.
  4. Bifoga aldrig en ProjectWorth-säkerhetskopia om du inte uttryckligen vill dela informationen i den.

Skydda dina data

Skapa en återställningsbar säkerhetskopia via Inställningar → Data → Säkerhetskopia → Skapa säkerhetskopia. En säkerhetskopia innehåller hela den lokala arbetsytan, inklusive projektdata och inställningar som ProjectWorth lagrar. Om databasen inte kan öppnas visar ProjectWorth ett återställningsläge där originalfilerna kan arkiveras innan du startar tomt.
